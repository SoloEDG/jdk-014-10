# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 导演预演模式

在工具栏切换到「导演」模式，为每格安排起止取景、停留与转场，把逐格阅读编排成有节奏的动态漫画。

- **镜头编排**：每格可设置起止取景框、起点/终点停留、缓动、移动速度、对白揭示与声音触发时刻。
- **安全可见区**：作者可在导演台收紧页面安全区，预演取景框始终被约束在区域内。
- **连续移动与防剧透**：转场支持连续平移或切镜。规划器对最短直线路径逐段采样，
  禁止镜头扫过尚未揭示的对白核心区及其后的分镜；存在冲突时列出替代路径
  （侧向/贴边/正交绕行、切镜兜底）并给出推荐，同时提示速度与揭示顺序的冲突。
- **时间线预演**：rAF 时钟驱动，支持播放、暂停、任意拖动。声音与对白按实际镜头进度
  对齐；已结束的触发不会因暂停后继续或拖动而重播（对白由时间线位置确定性推导）。
- **待修订边界**：布局改动或删除中间格只标记相关镜头（`stale`）。预演在第一个
  待修订格前明确停靠，失效段不会计入阅读进度；修订单格后自动恢复完整时间线。

## 数据兼容

旧版本地存档在加载时自动迁移：补齐页面安全区与每格默认镜头，不改动既有字段。

## 纯逻辑测试

测试位于仓库外的独立目录（避免污染项目），用 esbuild 打包后由 Node 内置 test runner 运行，
覆盖路径规划、安全区约束、时间线编译、cue 单次触发与失效修订：

```bash
../node_modules/.bin/esbuild planner.test.ts --bundle --platform=node \
  --format=esm --outfile=dist/planner.test.mjs
node --test dist/planner.test.mjs
```
